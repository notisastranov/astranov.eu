National boundaries use Natural Earth 1:110m Admin 0 geography (public domain), via world-atlas 2.0.2. The pack contains the shared country arcs from countries-110m.json, decoded with topojson-client's mesh and rounded to three decimals. Natural Earth depicts boundaries using its de facto policy. See borders.LICENSE for the World Atlas license.

The news region index uses country polygons from the same Natural Earth dataset. It indexes the countries with configured broadcaster feeds.

The event outline index contains Natural Earth country polygons from the same
world-atlas 2.0.2 `countries-110m.json` file. Coordinates are rounded to three
decimal places and each polygon includes a bounding box for event lookup.
